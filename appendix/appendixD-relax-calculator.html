D.1 How to Use

Use the Schema Definition textarea to define your tables using inline-relation syntax, then type a relational algebra expression in the Query Editor and click ▶ Execute (or press Ctrl+Enter).

D.1.1 Quick Reference — Symbol Bar

Group Symbols Meaning
RA Ops π σ ρ τ γ Projection, Selection, Rename, Order-by, Group-by
Assign ← → Assignment arrows
Logic ∧ ∨ ¬ And, Or, Not
Compare = ≠ ≥ ≤ Equality and inequalities
Set ∩ ∪ ÷ - Intersection, Union, Division, Difference
Join ⨝ ⟕ ⟖ ⟗ ⋉ ⋊ ▷ ⨯ Natural/outer/semi/anti/cross joins
Misc -- / * { } Comment, arithmetic, grouping

D.1.2 Example Queries

Try these on the pre-loaded Enhanced Company Database:

-- Select high-salary employees
σ Salary > 65000 (Employee)

-- Project only names and salary
π Fname, Lname, Salary (Employee)

-- Natural join employee with their assignments
Employee ⨝ Works_On

-- Left outer join (keep all employees, null if no assignment)
Employee ⟕ Works_On

-- Employees who are also managers (intersection by SSN)
π Ssn (Employee) ∩ π Mgr_ssn (Department)

-- Employees working on any project in Department 1
π Fname, Lname (σ Dnum = 1 (Employee ⨝ Works_On ⨝ Project))

-- Rename relation and column
ρ Emp ← π Ssn, Fname, Salary (Employee)

  function renderER(tables) {
    let html = '<div class="er-diagram">';
    for (const t of tables) {
      const fkSet = new Set(Object.keys(t.fk || {}));
      html += `<div class="er-table">`;
      html += `<div class="er-table-head${t.pk ? '' : ' leaf'}">${escHtml(t.name)}</div>`;
      for (const [col, type] of t.cols) {
        const isPK = col === t.pk;
        const isFK = fkSet.has(col);
        let cls = 'er-col';
        if (isPK) cls += ' er-col-pk';
        else if (isFK) cls += ' er-col-fk';
        let badges = '';
        if (isPK) badges += '<span class="er-badge er-pk">PK</span>';
        if (isFK) badges += `<span class="er-badge er-fk" title="→ ${escHtml(t.fk[col])}">FK</span>`;
        html += `<div class="${cls}">${badges}<span class="er-col-name">${escHtml(col)}</span><span class="er-col-type">${escHtml(type)}</span></div>`;
      }
      // FK legend
      const fkEntries = Object.entries(t.fk || {});
      if (fkEntries.length > 0) {
        const notes = fkEntries.map(([c,ref]) => `${escHtml(c)} → ${escHtml(ref)}`).join(' &nbsp;|&nbsp; ');
        html += `<div class="er-rel-note">${notes}</div>`;
      }
      html += `</div>`;
    }
    html += '</div>';
    return html;
  }

## How to Use

Use the **Schema Definition** textarea to define your tables using inline-relation syntax, then type a relational algebra expression in the **Query Editor** and click **▶ Execute** (or press **Ctrl+Enter**).

### Quick Reference — Symbol Bar

| Group | Symbols | Meaning |
|-------|---------|---------|
| **RA Ops** | `π` `σ` `ρ` `τ` `γ` | Projection, Selection, Rename, Order-by, Group-by |
| **Assign** | `←` `→` | Assignment arrows |
| **Logic** | `∧` `∨` `¬` | And, Or, Not |
| **Compare** | `=` `≠` `≥` `≤` | Equality and inequalities |
| **Set** | `∩` `∪` `÷` `-` | Intersection, Union, Division, Difference |
